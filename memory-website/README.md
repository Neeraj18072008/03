# Memory Website

A 10-page mobile-first romantic scrapbook experience.

## Run

```bash
pip install -r requirements.txt
python app.py
```

Open the preview URL on a phone or use browser device mode.

## Customize

1. Replace `YOUR PERSONAL MESSAGE HERE` and similar placeholders in `templates/index.html`.
2. Drop photos into `static/images/` using the names in `static/images/IMAGE-NAMES.txt`. Empty cards stay as labeled placeholders until a matching image is present.
3. Change the 6-digit password in `static/js/script.js` (`CORRECT_PASSWORD`).
